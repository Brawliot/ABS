# Elements

Instanciación de los 10 elementos del núcleo a partir del metaobjeto.

- Subtipos cerrados: `subtypes.ts`
- Ciclos derivados: `derived-lifecycles.ts`
- Proyección (principio 7): `projection.ts` — los ciclos derivados solo avanzan con eventos de transacción
- Invariantes de cierre de transacción: `closure.ts`
