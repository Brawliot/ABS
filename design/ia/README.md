# Arquitecto de información

Decide qué es principal en cada módulo **por rol**. Salida → capa superpuesta
(`PresentationOverlay.informationArchitecture`).

## Por rol
- **Inicio**: vistas/acciones destacadas + pendientes
- **Menú**: ≤7 entradas principales; resto en grupo «Más»
- **Vistas**: campos principales (`identificacion`, `estado`, `importe`, `plazo`)

## Aprendizaje
Datos del Observador de experiencia → **propuestas** (`proposeFromExperience`).
Nadie reordena solo: hace falta `approve` + materializar.
